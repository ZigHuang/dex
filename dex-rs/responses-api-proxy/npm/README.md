# @openai/dex-responses-api-proxy

<p align="center"><code>npm i -g @openai/dex-responses-api-proxy</code> to install <code>dex-responses-api-proxy</code></p>

This package distributes the prebuilt [Dex Responses API proxy binary](https://github.com/openai/dex/tree/main/dex-rs/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/dex-responses-api-proxy.js --help
```

Refer to [`dex-rs/responses-api-proxy/README.md`](https://github.com/openai/dex/blob/main/dex-rs/responses-api-proxy/README.md) for detailed documentation.
